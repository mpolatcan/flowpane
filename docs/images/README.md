# Screenshots

The README links to these four files. Each is a capture of the pane in a real
terminal — the ASCII renders elsewhere in the docs show the layout, and these
show the colour, which is half of what the drawing says.

| File | What to capture |
| --- | --- |
| `flow.png` | A run of three or more phases with the layout set to **across**, wide enough for cards: the header, the wires between the bands, and a mix of states so the green, yellow and red frames all appear. |
| `stack.png` | The same run with the layout set to **down**, and the Skipped band visible at the foot if the run has one. |
| `timeline.png` | The layout set to **timeline**, with the now-marker somewhere in the middle of the bars. |
| `detail.png` | A node's detail dialog open over the graph: the prompt, the tool calls and the answer, with the graph pushed back behind it. |

A light theme in one of the four is worth it — `github-light` or
`solarized-light` — so a reader can see the pane is not dark-only.

Capture at a terminal width of 120 columns or more. Trim to the pane; the
transcript beside it is not the subject.
